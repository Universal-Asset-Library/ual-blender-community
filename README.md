# Universal Asset Library (Blender Community)

Free Blender extension for browsing a local asset library and public online sources.

| | |
|---|---|
| **License** | GPL-3.0-or-later |
| **Blender** | 4.2+ (tested on 5.2) |
| **Current release** | **0.3.97** |
| **Website** | https://universalassetlibrary.com |

## Features

- Local library (index, favorites, import, health check)
- Hover preview
- Material Blend
- Online sources: Poly Haven, ambientCG, GPUOpen MaterialX, LazyTextures, Three D Scans, PBRPX, Poly Pizza, Sketchfab
- Check for Updates

## Install

1. Download the Community ZIP from [Releases](../../releases) or https://universalassetlibrary.com/download
2. In Blender 4.2+: **Edit > Preferences > Get Extensions > Install from Disk**
3. Enable **Allow Online Access** in Blender Preferences for online sources
